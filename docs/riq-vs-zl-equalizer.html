RiQ vs ZL Equalizer 2

RiQ is cheaper than ZL Equalizer 2 in all nine scenarios: 2.6–14 times at 30 instances, least with dynamic bands, most with many instances of a few bells. In the same runs ZL also costs 1.1–2 times as much as Pro-Q 4.

How it was measured

Method

  • A track gets N identical copies of the plugin over 60 s of noise and is frozen (offline render) three times. The best time minus that of a track without FX is the plugins’ cost.
  • The N = 10 run: 111 freezes, none discarded. The two N = 30 runs: 109 freezes and 5 discarded (“Nothing to render”) each; discarded ones were repeated, every cell has a result.
  • The “4 bells” and “HP+LP” scenarios always run 18 and 24 instances, so their rows have the same N in both modes.
  • Parameters are set by their displayed values, so every plugin gets the same curve. Windows builds of every plugin, run natively in Windows REAPER under Wine, with no bridge.

ZL settings and caveats

  • The AVX2 build: RiQ also runs its AVX2 path on this CPU. The .vst3 was taken out of the .msi without running the installer.
  • Minimum Phase structure (the default, zero latency). For linear phase, ZL’s Zero Phase against RiQ’s Medium: they work differently, so the comparison is rough.
  • Dynamics: threshold −30 dB, Target Gain = band gain − 6 dB (matching RiQ’s −6 dB range).
  • Figures below ~0.01 % and rows with different N can’t be compared with each other.
  • Checked by numbers, not by ear. That ZL processes the audio shows in its cost growing with the number of bands.
